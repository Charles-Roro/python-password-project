# 🔐 Simple Python Password Generator

This is a beginner-friendly Python script that generates strong, random passwords using a customizable mix of characters. It’s a great tool for practicing Python fundamentals while also building something practical and security-minded.

---

## 📌 What This Script Does

- ✅ Generates **10 unique passwords**
- ✅ Each password is **20 characters long**
- ✅ Uses a full set of characters:
  - Uppercase letters (`A–Z`)
  - Lowercase letters (`a–z`)
  - Numbers (`0–9`)
  - Symbols (`!@#$%^&*()`, etc.)
- ✅ Highly customizable for different use cases
